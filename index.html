02 — L'idée

Trois pièces.
Une seule station.

Le laptop tient dans un sac. Le bureau tient le laptop. Les trois ensemble tiennent un studio de développement et de gaming haut de gamme.

01

Le cerveau

Recoil 16

Autonome, nomade, capable. Ultra 9 275HX + RTX 5090 Laptop + 64 Go DDR5 dans 2,4 kg. Tout tient dans le laptop — l'Oasis et le G9 ne sont que des amplificateurs.

02

Le poumon

XMG Oasis

Au bureau, un câble et le watercooling prend le relais. Les clocks tiennent, les ventilos se taisent, les sessions longues ne dégradent plus les performances. On ne remarque même plus qu'il est branché.

03

L'horizon

Samsung Odyssey G9 49"

5120 × 1440 pour trois fenêtres côte à côte en dev, une immersion totale pour le gaming. La courbe 1800R épouse la vue, l'OLED rend les noirs parfaits.

04 — Workflow

Une journée type.

Le setup suit le rythme : le laptop se détache, se pose, se branche, se débranche.

  1. 07 : 30

    Mobile — Laptop seul

    Dans un café ou dans le train. Batterie, autonomie, juste le Recoil et un thermos. Code & emails.

  2. 09 : 00

    Station complète

    Au bureau. USB-C pour l'Oasis, DisplayPort pour le G9. 30 secondes et la machine respire, le 49" s'allume, trois fenêtres apparaissent.

  3. 14 : 00

    Création lourde

    Rendu DaVinci, build Docker, compilation longue — la boucle liquide encaisse, aucun throttle, ventilos à mi-régime.

  4. 21 : 30

    Gaming immersif

    Le 49" prend toute la vue, 240 Hz sur OLED, latence imperceptible. Le Recoil ne fait pas de bruit — l'Oasis fait le travail.
