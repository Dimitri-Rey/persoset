## Auto-download (optionnel)

Un script `download-images.sh` est fourni à la racine du projet.
Il nécessite `curl` et pré-remplit le dossier avec des exemples
(à remplacer par tes vraies photos ensuite).

```bash
bash download-images.sh
```

Si un fichier est absent, l'illustration SVG intégrée s'affiche à la place.
